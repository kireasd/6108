# 딸깍 쇼츠 공장

"아직도 손으로 편집하세요?"(도롱이) 전자책이 소개하는 **원클릭 쇼츠 자동 편집**을 참고해 만든 프로그램입니다.
해외 영상 URL을 넣고 채널만 고르면, 아래 과정을 자동으로 처리해 세로 쇼츠(1080×1920) mp4를 만듭니다.

```
영상 URL/파일 ─▶ ① 다운로드(yt-dlp) ─▶ ② 원본 자막 확보 ─▶ ③ AI 각색(Claude) ─▶ ④ 렌더(FFmpeg) ─▶ output/채널명/*.mp4 + 업로드용 .txt
```

| 단계 | 하는 일 |
|---|---|
| ① 다운로드 | YouTube·TikTok·Instagram 등 yt-dlp가 지원하는 사이트. 자막(사람 자막 > 자동 자막)도 같이 받습니다. 영상 파일을 직접 올려도 됩니다. |
| ② 자막 | 원본 자막을 정리(자동 자막 중복 줄 제거)합니다. 자막이 없고 `faster-whisper`가 설치되어 있으면 음성 인식으로 만듭니다. |
| ③ AI 각색 | Claude가 **2줄 후킹 제목 + 강조 단어**, **한국어 자막 번역**, **업로드 제목/설명/해시태그**를 만듭니다. API 키가 없으면 이 단계 없이 직접 입력한 제목과 원본 자막을 씁니다. |
| ④ 렌더 | 검정/흰/블러 배경 레이아웃에 제목·자막·워터마크를 넣고, 좌우 반전·배속·확대 크롭·최대 길이 같은 변형을 적용합니다. |

**채널 프리셋**: 채널마다 레이아웃·색·말투·변형 옵션을 저장해 둘 수 있습니다. 채널을 여러 개 운영해도 고르기만 하면 됩니다.
**일괄 처리**: URL을 여러 줄로 넣으면 대기열에 올라가 하나씩 처리됩니다.

## 실행

1. [FFmpeg](https://ffmpeg.org) 설치 (Windows: `winget install Gyan.FFmpeg`)
2. Python 3.10 이상 설치
3. Windows는 `run.bat` 더블클릭, macOS/Linux는 `./run.sh`
   → 브라우저에서 `http://127.0.0.1:5077`이 열립니다.
4. **설정** 탭에 Anthropic API 키를 넣으면 AI 제목·번역이 켜집니다 (키는 이 폴더의 `settings.json`에만 저장됩니다).

## 파일 구조

| 파일 | 역할 |
|---|---|
| `app.py` | 로컬 웹 서버 + 작업 대기열 |
| `pipeline.py` | 다운로드 → 자막 → AI → 렌더 파이프라인 |
| `ai.py` | Claude 호출 (구조화된 출력으로 제목/자막/메타데이터 생성) |
| `subtitles.py` | json3/vtt/srt 파싱, ASS(제목+자막) 생성 |
| `config.py` | 설정·채널 프리셋 저장, 한글 폰트 탐색 |

테스트: `python -m pytest tests`

원본 찾기

영상을 넣으면 장면마다 분석해서 원본 영상과 비슷한 결의 영상을 찾아 줘요. 결과는 화면에서 먼저 확인할 수 있어요.

선택한 영상이 없어요
AI 분석 결과

장면 사진 아래 구글 렌즈를 누르면 사진이 복사되고 구글 이미지 검색이 열려요. 검색창에서 Ctrl+V만 누르세요.

이 영상의 컨셉

⚠️ 다른 사람의 영상을 다시 올리면 저작권 문제가 생길 수 있어요. 원본 채널의 허락을 받았거나 사용이 허용된 영상만 쓰세요.

주제로 만들기

주제를 적으면 AI가 대본을 쓰고, 목소리·배경·자막을 붙여 쇼츠를 완성해요.

긴 영상 자르기

긴 영상을 넣으면 AI가 재밌는 부분을 골라 세로 쇼츠 여러 개로 만들어요.

선택한 영상이 없어요

1시간짜리 영상이면 10~20분쯤 걸려요. 처음 한 번은 음성 인식 AI를 내려받느라 더 걸려요.

만든 영상

완성 영상 폴더에 있는 영상이에요. 누르면 기본 동영상 플레이어로 열려요.

목소리와 배경
인터넷 전체 이미지 검색 (선택 · 유료)

키를 넣으면 원본 찾기 때 장면마다 인터넷 전체(틱톡·인스타 등)에서 같은 장면을 자동으로 찾아요. 키가 없어도 장면마다 구글 렌즈 버튼으로 무료로 찾을 수 있어요. 구글 클라우드(console.cloud.google.com)에서 Cloud Vision API를 켜고 API 키를 만드세요. 한 달 1,000장까지 무료, 그 뒤 1,000장에 약 5천 원이에요.

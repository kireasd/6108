# 🎬 쇼츠 자동 제작기

AI로 유튜브 쇼츠를 만드는 윈도우 프로그램이에요.

| 메뉴 | 하는 일 |
|---|---|
| 🔍 **원본 찾기** | 영상(파일 또는 링크)을 넣으면 장면마다 분석해서 **원본 영상**과 **비슷한 결의 영상**을 찾아 줘요. 결과를 화면에서 확인한 뒤 받거나 쇼츠로 만들 수 있어요. |
| ✍️ **주제로 만들기** | 주제를 적으면 AI가 대본을 쓰고, 목소리·배경·자막을 붙여서 쇼츠를 완성해요. |
| ✂️ **긴 영상 자르기** | 긴 영상을 넣으면 AI가 재밌는 부분을 골라 세로 쇼츠 여러 개로 잘라 줘요. |
| 🎞️ **만든 영상** | 완성한 쇼츠와 받아 둔 원본을 모아서 보여 줘요. |

AI는 **설정**에서 골라 쓸 수 있어요.
- **🏠 내 컴퓨터 AI**: 사용료 **0원**. 처음 설치할 때 8GB를 내려받아요.
- **💳 유료 AI (Claude / ChatGPT / Gemini)**: 키(API 키)를 넣으면 써요. 분석·대본 품질이 더 좋고, 쓴 만큼 조금씩 돈이 나와요.

완성된 영상은 **바탕화면 › 쇼츠** 폴더에, 받은 원본은 **바탕화면 › 쇼츠 › 원본** 폴더에 저장돼요.

---

## 처음 한 번만: 설치

1. 이 폴더(`shorts-maker`) 안의 **`install.bat`** 을 더블클릭해요.
2. 검은 창이 뜨고 설치가 진행돼요. 중간에 "허용하시겠어요?" 창이 뜨면 **예**를 눌러 주세요.
3. **"내 컴퓨터 AI도 설치할까요?"** 라고 물어보면:
   - **Y** → 무료 AI까지 설치 (8GB, 20~40분)
   - **N** → 유료 AI만 사용 (몇 분이면 끝나요. 나중에 `install.bat`을 다시 실행하면 설치할 수 있어요)
4. **"설치 완료!"** 가 나오면 아무 키나 눌러 창을 닫아요.

> 파란 창으로 "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행**을 눌러 주세요.

## 쓸 때마다: 실행

바탕화면의 **🎬 쇼츠 자동 제작기** 아이콘을 더블클릭하면 프로그램 창이 열려요.
(아이콘이 없으면 이 폴더의 `run.bat`을 더블클릭해도 돼요.)

## 새 버전으로 업데이트

프로그램을 끄고 **`update.bat`** 을 더블클릭하면 새 버전으로 바뀌어요. 보통 **1분 안에** 끝나요.
설정, 넣어 둔 키, 배경음악, 내 컴퓨터 AI는 **그대로** 남아요.

## 🔍 원본 찾기

**1. 영상 넣기** — 둘 중 편한 방법으로 넣어요.
- **📁 파일로 넣기**: 컴퓨터에 있는 영상 파일
- **🔗 링크로 넣기**: 유튜브·틱톡·인스타 등 영상 주소를 붙여 넣기 (비공개·로그인이 필요한 영상은 파일로 넣어 주세요)

**2. 옵션 고르고 원본 찾기 시작**
- **🎤 대사도 분석하기**: 대사가 없는 영상(음악·풍경 등)이면 끄면 더 빨라요. 켜도 최대 1분 30초까지만 들어요.
- **🔬 상위 5개 정밀 비교까지 자동으로**: 꺼 두면(기본) 결과를 **1분 안팎**으로 먼저 보여 주고, 궁금한 후보만 **🔬 정밀 확인** 버튼으로 확인해요.

아래 **진행 안내**에 지금 몇 단계인지, 몇 분째인지 나와요. 너무 오래 걸리면 오른쪽 **■ 그만하기**를 누르세요.
(처음 한 번은 음성 인식 AI를 내려받느라 5~15분 더 걸릴 수 있어요.)

**3. 결과 확인** — 아무것도 자동으로 받거나 만들지 않아요. 화면에서 먼저 확인하세요.

| 탭 | 보여 주는 것 |
|---|---|
| 🎞️ **장면별 확인** | 장면이 바뀌는 곳마다 나눈 장면 사진. 모음 영상이면 장면마다 원본이 달라서 장면별로 찾아요.<br>· **구글 렌즈 / 빙**: 누르면 장면 사진이 복사되고 검색창이 열려요 → **Ctrl+V** 누르면 끝 (무료)<br>· 💳 자동 검색을 켜면 장면마다 인터넷(틱톡·인스타 등)에서 찾은 페이지가 바로 떠요<br>· 유튜브 원본 후보와 맞은 장면이면 **🎯 원본 몇 분 몇 초**가 표시돼요 |
| 🎯 **원본 후보** | 유튜브에서 자동으로 찾은 후보. 점수가 높을수록 원본일 가능성이 커요.<br>· **🔬 정밀 확인**: 그 영상을 받아서 2초마다 장면을 맞춰 봐요 (20~60초)<br>· 정밀 확인을 하면 **내 장면과 원본 장면을 나란히** 보여 줘서 눈으로 확인할 수 있어요<br>· **60% 이상 · 원본 확실** / **30~60% · 원본 가능성** |
| ✨ **비슷한 결의 영상** | AI가 파악한 이 영상의 **컨셉·유행**과, 같은 컨셉의 다른 영상들.<br>· 유튜브·틱톡·인스타·구글 영상 **바로 검색 버튼**도 있어요 |

**4. 다음 단계** — 마음에 드는 영상에서 버튼을 눌러요.
- **⬇ 받기**: `쇼츠 › 원본` 폴더에 받아요 (유튜브 외 틱톡·인스타 등도 대부분 돼요)
- **✂️ 받아서 쇼츠 만들기**: 받은 다음 **긴 영상 자르기**로 넘어가요

### 인터넷 전체 자동 검색 켜기 (선택 · 유료)
키가 없어도 **구글 렌즈 버튼**으로 무료로 찾을 수 있어요. 장면마다 자동으로 찾고 싶으면:
1. https://console.cloud.google.com 에 구글 계정으로 로그인하고 결제 정보를 등록해요
2. **Cloud Vision API**를 검색해서 **사용**을 눌러요
3. **API 및 서비스 › 사용자 인증 정보 › API 키 만들기**
4. 프로그램 **⚙️ 설정 › 인터넷 전체 이미지 검색**에 키를 넣고 저장해요

한 달에 1,000장까지 무료이고, 그다음은 1,000장에 약 5천 원이에요. (영상 하나에 최대 8장 검색)

⚠️ 다른 사람의 영상을 다시 올리면 저작권 문제가 생길 수 있어요. 원본 채널의 허락을 받았거나 사용이 허용된 영상만 쓰세요.

## ✍️ 주제로 만들기

1. **① 주제** 칸에 만들고 싶은 내용을 적어요. (예: `고양이가 상자를 좋아하는 이유`)
2. **② 대본 만들기**를 눌러요. AI가 제목과 대본을 써 줘요.
3. 대본이 마음에 안 들면 **직접 고쳐도 돼요.** 한 줄이 한 장면이에요.
4. **③ 영상 만들기**를 누르면 1~3분 뒤에 영상이 완성돼요.

영상 옆에 같은 이름의 `.txt` 파일도 생겨요. 유튜브에 올릴 때 설명란에 쓰면 편해요.

## ✂️ 긴 영상 자르기

1. **🎬 긴 영상 선택**으로 영상을 골라요. (원본 찾기에서 받은 원본은 자동으로 들어가요)
2. 몇 개를 만들지 고르고 **쇼츠 만들기**를 눌러요. 1시간짜리 영상이면 10~20분쯤 걸려요.

## 유료 AI 쓰기

1. 쓰고 싶은 AI에 가입하고 **키(API 키)** 를 받아요.
   - Claude: https://console.anthropic.com → API Keys → Create Key
   - ChatGPT: https://platform.openai.com/api-keys → Create new secret key
   - Gemini: https://aistudio.google.com/apikey → Create API key (구글 계정으로 가입)
2. **⚙️ 설정 › AI 키와 모델**에서 해당 AI 칸을 열고 키를 붙여 넣어요.
3. **대본을 쓸 AI**에서 그 AI를 누르고, 맨 아래 **💾 설정 저장**을 눌러요.

> 키는 비밀번호와 같아요. 다른 사람에게 보여 주지 마세요. 키는 내 컴퓨터의 `settings.json`에만 저장돼요.

## 더 예쁘게 만들기 (선택)

- **배경 영상 넣기**: 그냥 쓰면 배경이 단색이에요. [Pexels](https://www.pexels.com/api/)에서 무료 키를 받아 **⚙️ 설정 › Pexels 키**에 넣으면 장면마다 어울리는 영상이 깔려요.
- **배경음악 넣기**: `bgm` 폴더에 mp3 파일을 넣으면 영상에 작게 깔려요. (저작권 없는 음악만 넣어 주세요)
- **목소리 바꾸기**: **⚙️ 설정**에서 목소리와 말하는 속도를 바꿀 수 있어요.

## 안 될 때

| 이런 메시지가 나오면 | 이렇게 해 보세요 |
|---|---|
| "Ollama가 켜져 있지 않아요" | 시작 메뉴에서 **Ollama**를 찾아 실행한 뒤 다시 눌러요. 설치를 안 했다면 `install.bat`에서 **Y** |
| "키가 없어요" / "키가 올바르지 않아요" | **⚙️ 설정**에서 키를 다시 붙여 넣고 저장해요 |
| "모델 이름을 찾을 수 없어요" | AI 회사가 모델 이름을 바꿨을 수 있어요. **⚙️ 설정**에서 모델 이름을 새 이름으로 바꿔요 |
| 원본 찾기에서 영상을 못 받음 | 유튜브가 바뀌었을 수 있어요. `update.bat`을 실행하면 유튜브 도우미가 최신으로 바뀌어요 |
| 목소리를 만드는 중에 멈춤 | 목소리는 **인터넷이 연결돼 있어야** 만들어져요 |
| 프로그램이 안 켜지거나 그 밖의 문제 | 이 폴더의 `app.log` 파일 내용을 보내 주세요 |

### 사용하는 도구
- 화면: pywebview (윈도우에 들어 있는 Edge WebView2로 창을 띄움)
- 분석·대본: [Ollama](https://ollama.com) + Gemma 3 (내 컴퓨터), 또는 Claude / ChatGPT / Gemini (유료)
- 말 알아듣기: Whisper (내 컴퓨터, 그래픽카드 사용)
- 유튜브 검색·다운로드: yt-dlp
- 목소리: Microsoft Edge 무료 음성 (인터넷 필요)
- 영상 편집: FFmpeg

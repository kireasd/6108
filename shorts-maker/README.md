# 🎬 쇼츠 자동 제작기

AI로 유튜브 쇼츠를 자동으로 만드는 프로그램이에요. AI는 두 가지 중 골라 쓸 수 있어요.

- **🏠 내 컴퓨터 AI**: 사용료 **0원**. 처음 설치할 때 8GB를 내려받아요.
- **💳 유료 AI (Claude / ChatGPT / Gemini)**: 키(API 키)를 넣으면 써요. 대본 품질이 더 좋고, 쓴 만큼 조금씩 돈이 나와요.

화면 맨 위 **🤖 대본을 쓸 AI**에서 언제든 바꿀 수 있어요.

- **🅰 주제로 만들기**: 주제를 적으면 AI가 대본을 쓰고, 목소리로 읽고, 배경과 자막을 붙여서 영상을 완성해요.
- **🅱 긴 영상 잘라 만들기**: 긴 영상을 넣으면 AI가 재밌는 부분을 골라 세로 쇼츠 여러 개로 잘라 줘요.

완성된 영상은 **바탕화면 › 쇼츠** 폴더에 저장돼요.

---

## 처음 한 번만: 설치

1. 이 폴더(`shorts-maker`) 안의 **`install.bat`** 을 더블클릭해요.
2. 검은 창이 뜨고 설치가 진행돼요. 중간에 "허용하시겠어요?" 창이 뜨면 **예**를 눌러 주세요.
3. **"내 컴퓨터 AI도 설치할까요?"** 라고 물어보면:
   - **Y** → 무료 AI까지 설치 (8GB, 20~40분)
   - **N** → 유료 AI만 사용 (몇 분이면 끝나요. 나중에 `install.bat`을 다시 실행하면 설치할 수 있어요)
4. 마지막에 **"설치 완료!"** 가 나오면 아무 키나 눌러 창을 닫아요.

> 파란 창으로 "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행**을 눌러 주세요.

## 쓸 때마다: 실행

1. **`run.bat`** 을 더블클릭해요.
2. 잠시 후 인터넷 창이 자동으로 열리고 프로그램 화면이 나와요.
3. 검은 창은 **닫지 말고 그대로** 두세요. 닫으면 프로그램이 꺼져요.

## 새 버전으로 업데이트

**`update.bat`** 을 더블클릭하면 새 버전으로 바뀌어요. 보통 **1분 안에** 끝나요.
- 설정, 넣어 둔 키, 배경음악, 내 컴퓨터 AI는 **그대로** 남아요.
- 업데이트하기 전에 프로그램(검은 창)은 꺼 주세요.

## 유료 AI 쓰기

1. 아래에서 쓰고 싶은 AI에 가입하고 **키(API 키)** 를 받아요.
   - Claude: https://console.anthropic.com → API Keys → Create Key
   - ChatGPT: https://platform.openai.com/api-keys → Create new secret key
   - Gemini: https://aistudio.google.com/apikey → Create API key (구글 계정으로 가입)
2. 프로그램의 **⚙ 설정**에서 해당 AI 칸을 열고 키를 붙여 넣은 뒤 **💾 설정 저장**을 눌러요.
3. 화면 맨 위 **🤖 대본을 쓸 AI**에서 그 AI를 골라요.

> 키는 비밀번호와 같아요. 다른 사람에게 보여 주지 마세요. 키는 내 컴퓨터의 `settings.json`에만 저장돼요.

## 🅰 주제로 만들기

1. **① 주제** 칸에 만들고 싶은 내용을 적어요. (예: `고양이가 상자를 좋아하는 이유`)
2. **② 대본 만들기**를 눌러요. AI가 제목과 대본을 써 줘요.
3. 대본이 마음에 안 들면 **직접 고쳐도 돼요.** 한 줄이 한 장면이에요.
4. **③ 영상 만들기**를 누르면 1~3분 뒤에 영상이 완성돼요.

영상 옆에 같은 이름의 `.txt` 파일도 생겨요. 유튜브에 올릴 때 설명란에 쓰면 편해요.

## 🅱 긴 영상 잘라 만들기

1. 긴 영상 파일을 화면에 **끌어다 놓아요.**
2. 몇 개를 만들지 고르고 **② 쇼츠 만들기**를 눌러요.
3. 1시간짜리 영상이면 10~20분쯤 걸려요.

## 더 예쁘게 만들기 (선택)

- **배경 영상 넣기**: 그냥 쓰면 배경이 단색이에요. [Pexels](https://www.pexels.com/api/)에서 무료 키를 받아 **⚙ 설정 › Pexels 키**에 넣으면, 장면마다 어울리는 영상이 배경으로 깔려요.
- **배경음악 넣기**: `bgm` 폴더에 mp3 파일을 넣으면 영상에 작게 깔려요. 여러 개를 넣으면 그중 하나를 골라 써요. (저작권 없는 음악만 넣어 주세요)
- **목소리 바꾸기**: **⚙ 설정**에서 목소리와 말하는 속도를 바꿀 수 있어요.

## 안 될 때

| 이런 메시지가 나오면 | 이렇게 해 보세요 |
|---|---|
| "Ollama가 켜져 있지 않아요" | 시작 메뉴에서 **Ollama**를 찾아 실행한 뒤 다시 눌러요. 설치를 안 했다면 `install.bat`에서 **Y** |
| "키가 없어요" / "키가 올바르지 않아요" | **⚙ 설정**에서 키를 다시 붙여 넣고 저장해요 |
| "모델 이름을 찾을 수 없어요" | AI 회사가 모델 이름을 바꿨을 수 있어요. **⚙ 설정**에서 모델 이름을 새 이름으로 바꿔요 |
| "모델이 설치되어 있지 않아요" | `install.bat`을 한 번 더 실행해요 |
| 목소리를 만드는 중에 멈춤 | 목소리는 **인터넷이 연결돼 있어야** 만들어져요 |
| 그 밖의 문제 | 검은 창에 나온 글자를 사진 찍어서 물어봐 주세요 |

### 사용하는 도구
- 대본·구간 고르기: [Ollama](https://ollama.com) + Gemma 3 (내 컴퓨터에서 실행), 또는 Claude / ChatGPT / Gemini (유료)
- 말 알아듣기: Whisper (내 컴퓨터에서 실행, 그래픽카드 사용)
- 목소리: Microsoft Edge 무료 음성 (인터넷 필요)
- 영상 편집: FFmpeg

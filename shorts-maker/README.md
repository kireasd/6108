# 🎬 쇼츠 자동 제작기

내 컴퓨터 안의 AI로 유튜브 쇼츠를 자동으로 만드는 프로그램이에요. **AI 사용료는 0원**이에요.

- **🅰 주제로 만들기**: 주제를 적으면 AI가 대본을 쓰고, 목소리로 읽고, 배경과 자막을 붙여서 영상을 완성해요.
- **🅱 긴 영상 잘라 만들기**: 긴 영상을 넣으면 AI가 재밌는 부분을 골라 세로 쇼츠 여러 개로 잘라 줘요.

완성된 영상은 **바탕화면 › 쇼츠** 폴더에 저장돼요.

---

## 처음 한 번만: 설치

1. 이 폴더(`shorts-maker`) 안의 **`install.bat`** 을 더블클릭해요.
2. 검은 창이 뜨고 설치가 진행돼요. **20~40분** 정도 걸려요. 중간에 "허용하시겠어요?" 창이 뜨면 **예**를 눌러 주세요.
3. 마지막에 **"설치 완료!"** 가 나오면 아무 키나 눌러 창을 닫아요.

> 파란 창으로 "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행**을 눌러 주세요.

## 쓸 때마다: 실행

1. **`run.bat`** 을 더블클릭해요.
2. 잠시 후 인터넷 창이 자동으로 열리고 프로그램 화면이 나와요.
3. 검은 창은 **닫지 말고 그대로** 두세요. 닫으면 프로그램이 꺼져요.

## 🅰 주제로 만들기

1. **① 주제** 칸에 만들고 싶은 내용을 적어요. (예: `고양이가 상자를 좋아하는 이유`)
2. **② 대본 만들기**를 눌러요. AI가 제목과 대본을 써 줘요.
3. 대본이 마음에 안 들면 **직접 고쳐도 돼요.** 한 줄이 한 장면이에요.
4. **③ 영상 만들기**를 누르면 1~3분 뒤에 영상이 완성돼요.

영상 옆에 같은 이름의 `.txt` 파일도 생겨요. 유튜브에 올릴 때 설명란에 쓰면 편해요.

## 🅱 긴 영상 잘라 만들기

1. 긴 영상 파일을 화면에 **끌어다 놓아요.**
2. 몇 개를 만들지 고르고 **② 쇼츠 만들기**를 눌러요.
3. 1시간짜리 영상이면 10~20분쯤 걸려요.

## 더 예쁘게 만들기 (선택)

- **배경 영상 넣기**: 그냥 쓰면 배경이 단색이에요. [Pexels](https://www.pexels.com/api/)에서 무료 키를 받아 **⚙ 설정 › Pexels 키**에 넣으면, 장면마다 어울리는 영상이 배경으로 깔려요.
- **배경음악 넣기**: `bgm` 폴더에 mp3 파일을 넣으면 영상에 작게 깔려요. 여러 개를 넣으면 그중 하나를 골라 써요. (저작권 없는 음악만 넣어 주세요)
- **목소리 바꾸기**: **⚙ 설정**에서 목소리와 말하는 속도를 바꿀 수 있어요.

## 안 될 때

| 이런 메시지가 나오면 | 이렇게 해 보세요 |
|---|---|
| "Ollama가 켜져 있지 않아요" | 시작 메뉴에서 **Ollama**를 찾아 실행한 뒤 다시 눌러요 |
| "모델이 설치되어 있지 않아요" | `install.bat`을 한 번 더 실행해요 |
| 목소리를 만드는 중에 멈춤 | 목소리는 **인터넷이 연결돼 있어야** 만들어져요 |
| 그 밖의 문제 | 검은 창에 나온 글자를 사진 찍어서 물어봐 주세요 |

---

### 사용하는 무료 도구
- 대본·구간 고르기: [Ollama](https://ollama.com) + Gemma 3 (내 컴퓨터에서 실행)
- 말 알아듣기: Whisper (내 컴퓨터에서 실행, 그래픽카드 사용)
- 목소리: Microsoft Edge 무료 음성 (인터넷 필요)
- 영상 편집: FFmpeg
